# BreakWise 🌿

A digital wellness and mindful study companion for students and thinkers.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

1. **Focus & Planned Rest Planner** (`/app`):
   - Set focus duration paired with guaranteed screen-free breaks.
   - Audio chime cues using gentle harmonic Web Audio frequencies.
   - Categorized screen-free rest ideas (Physical, Mindful, Unplugged).

2. **Notification Audit** (`/audit`):
   - Triage notifications into Immediate, Scheduled Digest, or Muted.
   - Real-time impact calculator estimating focus hours reclaimed.
   - Step-by-step iOS and Android notification setup guides.

3. **Mindful Scrolling & Bedtime Wind-Down** (`/wind-down`):
   - The 3-Breath Pause interactive animation to break reflex doomscrolling.
   - Conscientious scrolling timer caps (5m, 10m, 15m).
   - Circadian 90-minute sleep cycle calculator with customizable evening rituals.

4. **Anti-Shame Habit Reflection Dashboard** (`/dashboard`):
   - Non-judgmental weekly rhythm visualization (zero broken streaks).
   - Celebrates both focus time and restorative rest time.
   - Daily micro-journal for capturing offline joys.
